# Interaktive Lernlandkarten – Brennstoffe und Verbrennung

GitHub-Pages-fertiger, statischer Unterrichtskurs für **90 Minuten**: Blockwoche 1 (30 min), Blockwoche 2 (30 min), Zusammenfassung/Reflexion/Abgabe (30 min).

## Aufbau
- Startseite: nur die zwei originalen Lernlandkarten als klickbare Kurskarten.
- In jeder Blockwoche: Original-Lernlandkarte in voller Größe und 4 klickbare Themenfelder (entsprechend 01–04).
- Je Themenfeld: Infoquelle, multiple-choice/Zuordnung, offene Antworten und/oder Rechenfragen mit unmittelbarer Kontrolle bzw. Musterlösung.
- Abschluss: Zusammenfassung, Reflexion, Name/Klasse und **HTML-Abgabedatei**, die alle Antworten enthält.
- Original-PDF und Bildvorlagen liegen unter `assets/`. Keine externen JavaScript-Abhängigkeiten.

## GitHub Pages
1. Die **Inhalte** dieses Ordners (`index.html`, `style.css`, `script.js`, `assets/` und `README.md`) in das Root-Verzeichnis eines GitHub-Repositories hochladen.
2. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Den veröffentlichten GitHub-Pages-Link an die Klasse verteilen.

## Schüler-Abgaben / Datenschutz
GitHub Pages kann als statisches Hosting **keine Schülerdateien empfangen und speichern**. Deshalb laden Lernende mit dem Button „Abgabedatei herunterladen“ ihre persönliche HTML-Auswertung herunter und geben sie **über eine bereits vorhandene, durch die Schule zugelassene Plattform** ab (etwa Moodle-Aufgabe, IServ-Abgabe oder Teams-Aufgabe). Keine automatische Einsammlung; hierfür ist eine externe Plattform oder ein Backend mit Zugangs- und Datenschutzkonzept nötig. Bitte nicht Schülernamen und Antworten in ein öffentliches GitHub-Repository committen.

Eingaben werden lokal im Browser gespeichert (`localStorage`), nicht über GitHub synchronisiert. Browser-/Gerätewechsel übernimmt die Eingaben nicht. Auswertungen offener Texte erfolgen als Selbstkontrolle anhand von Musterlösungen; sie sind **keine automatische Fachbewertung**.

## Fachhinweise
Die beiden gelieferten Abbildungen werden unverändert eingeblendet. Die Quizfragen sind an den vier Themenbereichen jeder Lernlandkarte sowie dem gelieferten Arbeitsblatt orientiert und erweitern sie mit kurzen fachlichen Infotexten. Die Übungsrechnungen zum Brennstoffbedarf sind ausdrücklich idealisiert und nutzen die Vorgabewerte des Arbeitsblatts. Externe Recherche: DVGW, FNR, UBA und BDEW (Links im Abschlussbereich).
